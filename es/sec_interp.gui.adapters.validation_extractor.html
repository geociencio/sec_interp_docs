sec_interp.gui.adapters.validation_extractor module

Validation extraction adapter (Extract phase).

Bridges the QGIS object world and the QGIS-agnostic core validation layer by converting QgsVectorLayer/QgsRasterLayer objects (and project lookups) into detached LayerMetadata records.

sec_interp.gui.adapters.validation_extractor.build_validation_params(params: Any) → Any

Build a ValidationParams from a PreviewParams object.

Converts each QGIS layer reference held by params into detached LayerMetadata records.

Parámetros:

params – A PreviewParams instance holding QGIS layer references.

Devuelve:

A ValidationParams with detached layer metadata.

sec_interp.gui.adapters.validation_extractor.extract_section_line_metrics(layer_ref: Any, feature_id: int | None = None) → tuple[int | None, float | None]

Return (vertex_count, length) of the section feature.

Best-effort and defensive (Extract phase): reads the section line geometry once so the core 2-point invariant can be validated with primitives. Returns (None, None) when the geometry cannot be read, so the core rule is simply skipped rather than failing the whole validation.

Parámetros:

  • layer_ref – A layer object, ID, or name.

  • feature_id – Section feature id (first feature when None).

Devuelve:

Tuple of (vertex count, planar length). Both None when unavailable.
